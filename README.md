# Pagina-Cafe

Landing page responsiva hecha con Bootstrap 5 para una cafeteria. El proyecto incluye:

- Navbar responsiva y fija
- Carousel con 3 imagenes
- Cards con botones
- Modal promocional
- Formulario de contacto
